# FVM Tap

Mobile-first branded landing pages for FletchVibez Media NFC and QR products.

## Customer URLs

Customer pages use `/{slug}`. Customer profiles are managed in `src/clients.ts`.

The FletchVibez Media NFC contact card is available at `/fvm-contact`.

## Cloudflare

- Build command: `npm run check`
- Deploy command: `npm run deploy`
- Production domain: `tap.fletchvibezmedia.com`

The included profiles are demonstrations. Replace their review URLs before programming a production NFC product.
